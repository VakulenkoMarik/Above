# Above
Above is an exciting arcade game where players defy gravity! Your goal is to ascend as high as possible, bouncing off walls and dodging dangerous obstacles. This game is perfect for those who love dynamic gameplay and want to test their reflexes.

## 📖 Game Description
Take control of a character flying upward, constantly facing new challenges:

Bounce off walls to keep moving higher.
Dodge obstacles that stand in your way.
Climb as high as you can while collecting bonuses and avoiding traps.
The higher you go, the tougher the obstacles become!

## 🎮 Game Features
Simple controls, suitable for players of all skill levels.
Thrilling arcade mechanics that keep you on edge until the very end.
Minimalist design with vibrant visual effects.
Endless mode: break your own records!

## 🛠 Development
The game is created by an independent developer, Vakulenko Marian, also known as G9.
